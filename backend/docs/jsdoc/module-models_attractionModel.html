Module: models/attractionModel

Modèle chargé de la gestion des attractions dans la base de données PostgreSQL de WildPeak.

Il permet de récupérer toutes les attractions, d'en ajouter, de modifier leurs informations et de les supprimer.

Les opérations utilisent des requêtes SQL paramétrées pour transmettre les valeurs à PostgreSQL.

(async, inner) addAttraction(attractionData) → {Promise.<(Object|undefined)>}

Ajoute une nouvelle attraction dans la base de données.

Insère les informations de l'attraction dans la table attraction à l'aide d'une requête SQL paramétrée.

Le nom, le slug, les caractéristiques techniques, les descriptions et les informations du parc associé sont transmis depuis le controller.

Le slug et le texte alternatif de l'image sont générés en amont avant l'appel de cette fonction.

La clause RETURNING permet de récupérer toutes les informations de l'attraction après son insertion.

Les images ne sont pas traitées directement par ce modèle. Leur gestion est assurée séparément.

(async, inner) deleteAttraction(id) → {Promise.<(Object|null)>}

Supprime une attraction de la base de données.

Exécute une requête DELETE sur la table attraction pour supprimer l'enregistrement correspondant à l'identifiant fourni.

La clause RETURNING permet de récupérer les informations de l'attraction supprimée.

Si aucune attraction ne correspond à l'identifiant, la fonction retourne null.

Cette fonction supprime uniquement l'enregistrement PostgreSQL. Elle ne gère pas directement la suppression des images du stockage externe.

(async, inner) updateAttraction(id, attractionData) → {Promise.<(Object|null)>}

Modifie les informations d'une attraction existante.

Exécute une requête UPDATE sur la table attraction afin de remplacer les informations de l'attraction correspondant à l'identifiant fourni.

Les données modifiables comprennent le nom, le slug, le parc associé, les caractéristiques techniques, le niveau d'intensité, les descriptions et les informations destinées aux familles.

Les nouvelles valeurs sont fournies par le controller, qui effectue notamment la génération du slug et la conversion des champs numériques.

La clause RETURNING permet de récupérer les informations de l'attraction après modification.

Si aucune attraction ne correspond à l'identifiant, la fonction retourne null.
