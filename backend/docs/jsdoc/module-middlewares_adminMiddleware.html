Module: middlewares/adminMiddleware

Middleware chargé de contrôler les droits d'administration des utilisateurs de WildPeak.

Il permet de restreindre l'accès aux routes administrateur aux utilisateurs authentifiés possédant le rôle "admin".

Ce middleware doit être utilisé après authMiddleware, qui renseigne req.user.
