Module: services/mailService

Service chargé de l'envoi des e-mails de WildPeak à l'aide de l'API transactionnelle Brevo.

Il permet d'envoyer les messages provenant du formulaire de contact et les e-mails de réinitialisation des mots de passe.

Les informations de configuration et la clé API Brevo sont récupérées depuis les variables d'environnement du backend.

(async, inner) sendContactMail(contactData) → {Promise.<Object>}

Envoie un e-mail depuis le formulaire de contact WildPeak.

Récupère les informations saisies par le visiteur et construit un message contenant son nom, son prénom, son adresse e-mail et le contenu de sa demande.

Le message est envoyé via l'API Brevo à l'adresse définie dans la variable BREVO_RECEIVER_EMAIL.

L'adresse du visiteur est renseignée dans replyTo afin de permettre une réponse directe à son message.

La requête utilise la méthode POST et transmet les informations au format JSON.

Si l'API retourne une erreur HTTP, celle-ci est affichée dans la console et une exception est levée.

(async, inner) sendResetPasswordEmail(email, resetUrl) → {Promise.<Object>}

Envoie un e-mail de réinitialisation de mot de passe.

Cette fonction est appelée lors d'une demande de réinitialisation du mot de passe d'un utilisateur.

Elle construit un e-mail HTML contenant un lien permettant d'accéder au formulaire de modification du mot de passe.

Le lien de réinitialisation est généré en amont par le contrôleur d'authentification.

Le message informe l'utilisateur que le lien possède une durée de validité de 15 minutes.

L'e-mail est envoyé à l'adresse de l'utilisateur via l'API transactionnelle Brevo.

Si l'API retourne une erreur HTTP, une exception est levée avec le message fourni par Brevo ou un message d'erreur générique.

Parameters:
Name Type Description
email string

Adresse e-mail du destinataire.
resetUrl string

URL contenant le token de réinitialisation.
