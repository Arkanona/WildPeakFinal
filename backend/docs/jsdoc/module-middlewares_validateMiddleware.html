Module: middlewares/validateMiddleware

Middleware générique de validation des données envoyées au backend de WildPeak.

Il utilise la bibliothèque Zod pour vérifier que les données reçues dans le corps des requêtes HTTP respectent les schémas de validation définis.

Si les données sont invalides, une réponse HTTP 422 est retournée avec le détail des erreurs.

Si les données sont valides, elles sont remplacées par les données analysées par Zod avant de poursuivre le traitement de la requête.

Methods

(inner) validateBody(schema) → {function}

Crée un middleware Express de validation avec Zod.

Reçoit un schéma Zod et retourne une fonction middleware chargée de valider le contenu de req.body.

La méthode safeParse() permet de vérifier les données sans déclencher d'exception en cas d'échec de validation.

Si la validation échoue, le middleware retourne une réponse HTTP 422 contenant les champs invalides et les messages d'erreur associés.

Si la validation réussit, req.body est remplacé par result.data, puis next() est appelé pour transmettre la requête au traitement suivant.
