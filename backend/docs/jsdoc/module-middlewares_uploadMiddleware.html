Module: middlewares/uploadMiddleware

Middleware chargé de la gestion des fichiers images envoyés vers le backend de WildPeak.

Il utilise Multer pour traiter les fichiers transmis dans les requêtes multipart/form-data.

Les fichiers sont stockés temporairement en mémoire avant leur traitement avec Sharp et leur envoi vers le stockage Supabase.

Seuls les formats JPEG, PNG et WebP sont acceptés. La taille maximale autorisée est de 6 Mo par fichier.

(inner, constant) upload :Object

Configure le middleware Multer utilisé pour l'upload des images de WildPeak.

La configuration applique les règles suivantes :

  • Stockage temporaire en mémoire.
  • Taille maximale de 6 Mo par fichier.
  • Formats acceptés : JPEG, PNG et WebP.

Les fichiers dont le type MIME n'est pas autorisé sont rejetés avec une erreur.

Methods

(inner) fileFilter(req, file, cb) → {void}

Vérifie que le type MIME du fichier envoyé est autorisé.

Compare le type MIME du fichier avec la liste des formats acceptés : image/jpeg, image/png et image/webp.

Si le format est invalide, une erreur est transmise au callback.

Si le format est accepté, le callback autorise la poursuite du traitement.
