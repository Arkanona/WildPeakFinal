Module: models/parkModel

Modèle chargé de la gestion des parcs dans la base de données PostgreSQL de WildPeak.

Il permet de récupérer les parcs, de rechercher un parc par son identifiant, d'ajouter, de modifier et de supprimer des parcs.

Il permet également de compter les attractions associées à un parc avant sa suppression.

(async, inner) addPark(parkData) → {Promise.<(Object|undefined)>}

Ajoute un nouveau parc dans la base de données.

Insère les informations du parc dans la table park à l'aide d'une requête SQL paramétrée.

Le slug est généré en amont par le controller et transmis au modèle avec les autres informations.

La clause RETURNING permet de récupérer toutes les données du parc après son insertion.

(async, inner) countAttractions(id) → {Promise.<number>}

Compte le nombre d'attractions associées à un parc.

Exécute une requête SQL sur la table attraction afin de compter les attractions dont l'identifiant de parc correspond à celui fourni.

Le résultat SQL est converti en entier grâce à l'opérateur ::integer de PostgreSQL.

Cette fonction est notamment utilisée avant la suppression d'un parc pour vérifier qu'il ne contient plus d'attractions.

(async, inner) deletePark(id) → {Promise.<(Object|null)>}

Supprime un parc de la base de données.

Exécute une requête DELETE sur la table park pour supprimer le parc correspondant à l'identifiant.

La vérification de la présence d'attractions associées est effectuée en amont par le controller.

La clause RETURNING permet de récupérer les informations du parc supprimé.

Si aucun parc ne correspond à l'identifiant, la fonction retourne null.
