Module: middlewares/authMiddleware

Middleware d'authentification JWT de WildPeak.

Il permet de protéger les routes nécessitant une authentification utilisateur.

Le middleware récupère le token JWT depuis l'en-tête Authorization, vérifie sa validité et recherche l'utilisateur correspondant dans la base de données PostgreSQL.

Si l'authentification réussit, les informations de l'utilisateur sont ajoutées à req.user et la requête est transmise au middleware suivant.
